# 🛍️ Mantra E-Commerce Platform

Welcome to **Mantra**, a premium, full-stack, AI-powered e-commerce ecosystem. Mantra offers a highly interactive, dynamic, and professional user experience combined with a robust and scalable Node.js backend.

## 🚀 Features

- **Modern Premium UI:** A stunning, vibrant dark neon theme with smooth glassmorphism effects and animations.
- **Full-Stack Architecture:** Vanilla HTML/CSS/JS frontend seamlessly integrated with a Node.js/Express backend.
- **Advanced Authentication:** Secure JWT-based authentication combined with Firebase for Google Login.
- **Role-Based Access Control:** Distinct roles for `user`, `seller`, and `admin` with dedicated dashboards.
- **AI-Powered Assistant:** Integrated with OpenAI (GPT-3.5) for smart shopping assistance and automated SEO/Product descriptions for sellers.
- **Secure Payments:** Real-time, secure payment processing using the Razorpay gateway.
- **Gamification:** Interactive spin-the-wheel promotions and robust rewards systems to enhance user engagement.

## 🛠️ Tech Stack

### Frontend
- HTML5, CSS3, JavaScript (Vanilla)
- Premium CSS Custom Properties for responsive Dark Mode.

### Backend
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB Atlas (with Mongoose ODM)
- **Authentication:** JWT, Firebase Admin SDK
- **Payments:** Razorpay API
- **AI:** OpenAI API
- **Security & Performance:** Helmet, Morgan, Express Rate Limit, CORS.
